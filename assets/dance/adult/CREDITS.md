# 18+ visuals pack — credits

This folder is a gated catalog (`assets/dance/adult/`). The player loads it only when an admin has turned on **18+ visuals** for the signed-in user. The server serves these files only to those users (after the `music_server.py` patch is picked up on the next restart).

Scope: clearly adult characters in swimwear / club / party outfits, and sensual club-style dance moves (twerk, body roll, hip sway, pole-style, Latin, dancehall). Never nudity, sexual acts, fetish or porn, youthful-looking or chibi models, or franchise characters. Every item must be freely licensed for redistribution (CC0, CC-BY, or an explicit redistribution licence).

Built: 2026-11-11 11:29 Asia/Calcutta (IST).

## Characters

None. A search of allowlisted and other redistribution-friendly sources did not turn up a clearly adult, non-youthful, non-franchise, non-nude VRM in swimwear or club/party outfits under CC0, CC-BY, or an equally clear redistribution licence (VRoid Hub bikini models were skipped: several forbid corporate or commercial use, and many are visually ambiguous / youthful-coded). Moves alone are shipped. A future, hand-vetted model can be added via `assets/viz/update/vrm-allowlist-adult.json`.
